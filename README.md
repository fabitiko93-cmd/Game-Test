# Realmfall: Ashen Vale

Mobile-first dark-fantasy action RPG built in Godot 4 and deployed to GitHub Pages.

Design target: early-2000s console hack-and-slash feel — fixed isometric camera, direct melee combat, dungeon exploration, enemy groups, loot, progression and touch controls — with original characters, environments and assets.

## Project layout
- `godot/` — source project
- `docs/` — generated Web export for GitHub Pages
- `.github/workflows/godot-pages.yml` — automated Godot Web build/deploy pipeline
