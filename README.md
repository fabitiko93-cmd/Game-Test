# SPERRKREIS 98

Mobile-first isometric survival game set in a fictional Brandenburg town at the end of the 1990s.

The first playable slice combines grounded zombie-survival systems with the clear world interaction and isometric presentation of classic online role-playing games.

## Play

The published build lives in `docs/` and is designed for Safari on iPhone in landscape orientation.

## Controls

- Hold and drag on the left side to move; distance controls walking and running.
- Tap highlighted objects or use the context button to interact.
- Use the right-side button to attack.
- Open the backpack to use, equip, or move items.

## Project

- `docs/` — dependency-free HTML5 game and GitHub Pages build
- `docs/src/` — modular JavaScript game source
- `docs/assets/` — original interface artwork
